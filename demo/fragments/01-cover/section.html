OVERVIEW

体系概览

ZhaoUI 由一份唯一的 Token 数据源驱动。改动色彩或风格只需在 Token 包里调整，所有组件与演示页自动跟随。

01

主题维度

六个维度可自由组合，互不干扰。

  • 品牌
  • 亮暗
  • 密度
  • 受众
  • 涨跌色
  • 风格
02

双受众

B 端追求信息密度与效率，C 端强调品牌感与触达。

  • B 端 · 14px
  • C 端 · 16px
03

Token 分层

基础与语义两层已落地，组件层持续补充。

  • 基础
  • 语义
  • 组件（规划）
04

技术栈

Vue 3 + TypeScript + Vite，无头组件基于 Reka UI。

  • Vue 3
  • Reka UI
  • Nuxt SSR
05

跨端策略

Electron 复用 Web；移动端仅提供 H5 适配。

  • Web
  • Electron
  • H5
06

浏览器基线

色彩在构建期由 OKLCH 生成并输出为 HEX；玻璃风格依赖 backdrop-filter，不支持时退回实色。

  • Chrome ≥ 111
  • Safari ≥ 16.4
  • Firefox ≥ 113
  • 建议值
