日期与时间

日期选择由「输入框 + 日历浮层」组成：输入框支持直接键入，日历支持全键盘操作。日历一律从周一开始，中文月份与星期，不可选的日期用灰色并说明原因，不会隐藏。

日期选择 Date picker

可直接输入，如 2026-10-01 或 2026/10/1
不可选的日期悬停或输入时给出原因
超出范围的日期置灰

日期范围 Range picker

先点开始日，移动鼠标预览范围，再点结束日；先点了较晚的日期会自动对调。桌面并排显示两个月，手机显示一个月，快捷项变成横向滚动的标签。

—

时间选择 Time picker

三列滚轮：小时、分钟、秒。滚动停下、点击或按 ↑ ↓ 都会选中；← → 在列间切换。

日期时间 Date-time

选好日期和时间后点「确定」

内嵌日历、日程圆点与热度

圆点表示当天有几类日程（最多 3 类）；热度用品牌色阶表示当天日程多少，适合看「哪几天忙」。

    按键（焦点在日历内）行为
    ← → ↑ ↓前一天 / 后一天 / 上一周 / 下一周；跨月时自动翻页
    Home / End本周周一 / 周日
    PageUp / PageDown上个月 / 下个月；加 Shift 为上一年 / 下一年
    Enter / Space选中当前日期（不可选日期无效）
    Esc关闭日历，焦点回到输入框且不改变已选值
    输入框内 ↓打开日历，焦点进入当前日期
