色彩

品牌色输入一个值，自动生成 10 级色阶。主色按对比度自动挑选，保证按钮文字满足 WCAG AA（4.5:1）。中性色与功能色跟随亮暗模式。

品牌色阶 --zh-brand-1 … 10

语义色 --zh-color-*

品牌色提取

整套主题从一个主色出发。上传 Logo，系统提取主色，并派生色阶、按钮文字色、暗色主色，以及玻璃拟态风格的背景光斑。没有 Logo 时使用默认靛蓝。

尺寸与层级

三件事：控件有三档尺寸；文字有五级强弱；界面元素有固定的叠放顺序。

组件尺寸 sm / md / lg

尺寸B 端C 端用在哪里
sm24px36px表格行内操作、工具栏、次要按钮
md（默认）32px44px表单、常规按钮、搜索框
lg40px52px页面主操作、登录、下单等关键动作

「密度」会整体加减 4px；sm 和 lg 始终是 md 减 8px 和加 8px。触屏设备最小 44px，所以 B 端手机上 sm 会被抬到 44px。

文字色与数字色

文字只用「文字令牌」，不随手取色。数字有两套颜色：涨跌色表示方向，好坏色表示对业务是好是坏。颜色永远不单独表达意思，必须配符号或图标。

文字色

品牌文字 · 强调、选中态--zh-color-primary-text
链接文字 · 可点击--zh-color-primary-text
成功文字 · 已完成、通过--zh-text-success
警告文字 · 待处理、即将到期--zh-text-warning
危险文字 · 错误、失败、必填提示--zh-text-danger
信息文字 · 提示、说明--zh-text-info
反色文字 · 深色底、主色底--zh-text-inverse—

状态文字用的是比状态填充色更深的「文字专用」版本（亮色下 5:1 以上），所以浅底上的小字也看得清。

特殊文本样式

搜索命中显示为 高亮；降价时旧价显示为 ¥199 ¥129； 邮箱 是必填项；提及同事用 @张三； 快捷键 Ctrl + K；行内代码 --zh-color-primary； 查看详情 用链接色并带下划线。

数字色：涨跌色与好坏色

涨跌色跟地区惯例走（顶部「涨跌色」可切换红涨绿跌 / 绿涨红跌）；好坏色是固定的语义色。成本上涨是「涨」，但对业务是「坏」，所以两套不能混用。

AI 语义与 SEO

这一页本身就遵循这些规则。GEO 与 AIO 的效果主要取决于内容质量，ZhaoUI 负责提供语义、结构化数据和机器可读文档这些载体。

第一版内置

  • 语义 HTML：header / nav / main / section，标题层级不跳级
  • ARIA 与键盘可达：表单标签、状态提示、焦点环
  • SSR 安全：导入组件时不访问 window
  • JSON-LD 组件：Article、FAQ、Product、Breadcrumb、Organization
  • 机器可读文档：每个组件的 Markdown 与 props JSON，加 llms.txt

AI 可操作性约定

控件带稳定的可访问名称和固定标识，方便浏览器智能体理解页面。

浏览器兼容

支持策略分三级。本演示页为了预览响应式，用了容器查询；产品构建用媒体查询兜底，Token 里的颜色也已在构建期算成静态值，不依赖 color-mix。以下版本号是设计依据，上线前以 caniuse 与实测为准。

当前浏览器不支持容器查询，本页的响应式预览可能不准确。产品构建使用媒体查询，不受影响。

支持等级

等级范围保证
一级Chrome / Edge ≥ 111（含最近 2 个版本）· Safari（macOS / iOS）≥ 16.4 · Firefox ≥ 113（含 ESR 115）· Electron ≥ 24 · Android WebView 与微信内置浏览器（Chromium ≥ 111）· iOS WKWebView ≥ 16.4完整功能，每次发版都测
二级Chrome 90–110 · Safari 15.4–16.3 · Firefox 100–112可用但降级：无容器查询，布局走媒体查询；弹窗用兜底层；不保证动效
不支持IE 11 · 旧版 Edge（EdgeHTML）· Safari < 15.4 · Android 4.x 内置浏览器不测试，也不做兜底

怎么保证

  • 统一浏览器目标：chrome >= 111, edge >= 111, safari >= 16.4, firefox >= 113, ios_saf >= 16.4, not dead，写入 Browserslist
  • 构建：PostCSS（autoprefixer + postcss-preset-env）按上述目标自动加前缀、降级
  • 自动化：Playwright 同时跑 Chromium、Firefox、WebKit，做截图对比
  • 真机：iOS Safari、Android Chrome、微信内置浏览器，每次发版前过一遍
